## How This File Is Updated

1. After each scan (upwork-scan, linkedin-scan, contra-scan, job-digest), the scan skill reads this file
2. For every job scoring 60+, extract its required skills from the job listing
3. Append new rows to the Demand Log
4. Recalculate the Gap Summary (aggregate counts, check windows)
5. If any gap skill crosses a threshold, add to Triggered Actions and notify user
6. Skills you already have (listed in "Current Skills You Have") are logged but excluded from Gap Summary
