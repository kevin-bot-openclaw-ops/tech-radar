Personal technology radar tracking AI/ML engineering skills and market demand.

**Live radar:** https://kevin-bot-openclaw-ops.github.io/tech-radar/

## Quadrants

- **Languages & Frameworks** — Python, Java, Spring Boot, FastAPI
- **Platforms & Tools** — AWS, Azure, Docker, Kubernetes, FAISS
- **Techniques** — RAG, Agentic AI, MLOps, Prompt Engineering

## Rings

| Ring | Meaning |
|------|---------|
| **Adopt** | In use today, market demand confirmed |
| **Trial** | Actively learning, portfolio projects in progress |
| **Assess** | Emerging signals, monitor next 2-3 scans |
| **Hold** | Deprioritise — skill gap or not strategic |

## Updating

1. Edit `radar.json` — add/move blips, update appearances count
2. Run `python3 scripts/generate-radar.py` — rebuilds `index.html`
3. Commit and push — GitHub Pages auto-deploys

History snapshots are saved in `history/` for tracking movement over time.
